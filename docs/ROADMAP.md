# UI Extender — план развития

## Сделано

- Панель действующих сделок на экране дипломатии с выбранным лидером: кто что отдаёт, сколько ходов осталось. Показываются только пункты со сроком: золото в ход, ресурсы, соглашения.

## Запланировано

### 1. Разовые пункты сделки

Показывать в карточке сделки то, что было передано сразу: разовое золото, города, великие произведения, дипломатическую благосклонность.

Игра удаляет разовые пункты из сделки в том же ходу, в котором сделка заключена. Пример из `Logs/DiplomacyDeals.log`:

```
Turn 35, Enacting Deal id 1001 for player 0 and 3
, Enacting Deal Item ID 3, from player 3, to player 0, type Gold, ... amount 5, duration 0
Turn 35, Removing expired Deal Items from id 1001 for player 0 and 3
, Removing expired Deal Item ID 3, from player 3, to player 0, type Gold, ... amount 5, duration 0
```

Поэтому мод должен сам запоминать содержимое сделки в момент принятия и хранить его в сохранении. Для сделок, заключённых до этой доработки, разовые пункты восстановить нельзя.

### 2. История сделок

Список завершённых и истёкших сделок с выбранным лидером. Игра удаляет сделку после окончания срока, поэтому историю тоже нужно записывать самим и хранить в сохранении. Опирается на запись из пункта 1.

### 3. Отдельный интерфейс в меню дипломатии

Вынести сделки из панели поверх лидера в собственный раздел меню дипломатии: вкладку или кнопку рядом с остальными действиями.

### 4. Импорт и экспорт в списке редких ресурсов

В списке «Редкие ресурсы» на экране сделки показывать, какие ресурсы сейчас импортируются и экспортируются по действующим сделкам.
